# NC Code Helper (v0.0.2)

NCデータ（Gコード）の編集効率を向上させる VS Code 拡張機能です。  
プログラム番号（Oコード）やシーケンス番号（Nコード）による階層的な**アウトライン表示**、および各種NCステートメントの**リアルタイムカラーハイライト/切替機能**を提供します。

---

## 主な機能

### 1. 階層型アウトライン（シンボル表示）
* **階層構造**: Oコード（プログラム番号）を親、Nコード（シーケンス番号）を子としてアウトライン上にネスト（階層化）表示します。
* **ブロック追従**: エディタ上のカーソル位置に合わせて、該当するプログラム番号やシーケンス番号がアウトライン上で自動的にハイライト選択されます。
* **コメント表示**: 行内にあるコメントテキストもあわせて表示されるため、加工工程の把握が容易になります。

### 2. カテゴリ別カラーハイライト＆トグル切り替え
NCコード内の各種要素を識別しやすいカラーで色分け表示します。NCカラー設定から、カテゴリごとにオン/オフを切り替え可能です（オフ時は灰色表示）。

| カテゴリ | 対象コード例 | トグルコマンド |
| :--- | :--- | :--- |
| **O** | `O1001` (プログラム番号) | `NC: Oコード（プログラム番号）の切替` |
| **N** | `N100` (シーケンス番号) | `NC: Nコード（シーケンス番号）の切替` |
| **G** | `G00`, `G01`, `G43.1` (Gコード) | `NC: Gコードの切替` |
| **M** | `M03`, `M08`, `M30` (Mコード) | `NC: Mコードの切替` |
| **FS** | `F500`, `S1500` (送り・主軸回転数) | `NC: F/Sコード（送り・回転）の切替` |
| **XYZ** | `X100.0`, `Y-50.5`, `Z10.0` (直線軸) | `NC: 直線軸（XYZ）の切替` |
| **ABC** | `A90.0`, `B0.0`, `C180.0` (回転軸) | `NC: 回転軸（ABC）の切替` |
| **THD** | `T0101`, `H01`, `D01` (工具・補正) | `NC: 工具・補正（THD）の切替` |
| **OTHERS** | `P`, `Q`, `R`, `I`, `J`, `K` など | `NC: Pなどその他のパラメータの切替` |
| **コメント** | `(註釈・コメント)` | 自動的に暗い灰色で表示 |

---

## 使い方

1. 拡張機能をインストール後、拡張子が `.nc` または `.gcode` のファイルを開きます。
2. VS Code のサイドバー「アウトライン」パネルを開くと、プログラム構造がツリー形式で表示されます。
3. ステータスバー（右下）に各カテゴリのボタン（`$(gear) G: ON` など）が表示されます。クリックすることで特定のコードのハイライト色をすばやく切り替えられます。

---

## 設定（Settings）

`settings.json` または VS Code の設定画面から各コードのカラー表示の初期状態を設定できます。

```json
{
  "ncCodeHelper.enableOColor": true,
  "ncCodeHelper.enableNColor": true,
  "ncCodeHelper.enableGColor": true,
  "ncCodeHelper.enableMColor": true,
  "ncCodeHelper.enableFSColor": true,
  "ncCodeHelper.enableXYZColor": true,
  "ncCodeHelper.enableABCColor": true,
  "ncCodeHelper.enableToolColor": true,
  "ncCodeHelper.enableOthersColor": true
}
```
