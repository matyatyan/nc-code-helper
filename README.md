# NC Code Helper (v0.0.6)

NCデータ（Gコード）の編集・解読効率を向上させる VS Code 拡張機能です。  
プログラム番号（Oコード）やシーケンス番号（Nコード）による階層的な**アウトライン表示**、各種NCステートメントの**リアルタイムカラーハイライト/切替機能**、および**設備ごとのMコード定義参照機能**を提供します。

---

## 主な機能

### 1. 設備一覧（Mコード参照 & ポップアップ表示）
エクスプローラーサイドバーに独立した「設備一覧 (Mコード参照)」パネルを提供します。
* **設備JSON管理**: 指定フォルダ内の設備定義JSONを一覧表示し、新規JSONファイルの追加や保存フォルダの直接開閉が可能です。
* **Webview表示**: 設備名をクリックすると、右隣のタブに専用デザインのMコード一覧表をクリアに表示します。
* **ホバー表示**: 設備名ごとのチェックボックス形式によるON/OFFにより、Mコードの説明がポップアップ表示されます。

### 2. 階層型アウトライン（シンボル表示）
* **階層構造**: Oコード（プログラム番号）を親、Nコード（シーケンス番号）を子としてアウトライン上にネスト（階層化）表示します。
* **ブロック追従**: エディタ上のカーソル位置に合わせて、該当するプログラム番号やシーケンス番号がアウトライン上で自動的にハイライト選択されます。
* **コメント表示**: 行内にあるコメントテキストもあわせて表示されるため、加工工程の把握が容易になります。

### 3. NCカラー設定（カテゴリ別カラーハイライト）
エクスプローラーサイドバーの「NC カラー設定」パネルおよびステータスバーから、カテゴリごとにハイライトのオン/オフをチェックボックス形式ですばやく切替可能です（オフ時は灰色表示）。

| カテゴリ | 対象コード例 | トグルコマンド |
| :--- | :--- | :--- |
| **O** | `O1001` (プログラム番号) | `NC: Oコード（プログラム番号）の切替` |
| **N** | `N100` (シーケンス番号) | `NC: Nコード（シーケンス番号）の切替` |
| **G** | `G00`, `G01`, `G43.1` (Gコード) | `NC: Gコードの切替` |
| **M** | `M03`, `M08`, `M30` (Mコード) | `NC: Mコードの切替` |
| **FS** | `F500`, `S1500` (送り・主軸回転数) | `NC: F/Sコード（送り・回転）の切替` |
| **XYZ** | `X100.0`, `Y-50.5`, `Z10.0` (直線軸) | `NC: 直線軸（XYZ）の切替` |
| **ABC** | `A90.0`, `B0.0`, `C180.0` (回転軸) | `NC: 回転軸（ABC）の切替` |
| **THD** | `T0101`, `H01`, `D01` (工具・補正) | `NC: 工具・補正（THD）の切替` |
| **OTHERS** | `P`, `Q`, `R`, `I`, `J`, `K` など | `NC: Pなどその他のパラメータの切替` |
| **MACRO** | `#500`, `IF`, `GOTO`, `THEN` など | `NC: マクロ変数・構文の切替` |
| **コメント** | `(註釈・コメント)` | 自動的に暗い灰色で表示 |

## 使い方

1. 拡張機能をインストール後、対応拡張子（`.nc`, `.gcode` など）のファイルを開きます。
2. **サイドバー（エクスプローラー）**:
   - **「設備一覧 (Mコード参照)」**: 設備定義JSONの選択・追加・Webview表示ができます。
    ```json
    {
      "machine": "設備名",
      "description": "説明文",
      "version": "1.0.0",
      "mCodes": {
        "M00": "プログラムストップ",
        "M01": "オプショナルストップ",
      }
    }
    ```
   
   - **「NC カラー設定」**: チェックボックスで各カテゴリの色付け表示の切替が可能です。
3. **アウトラインパネル**: VS Code 標準のアウトラインビューにプログラム構造がツリー表示されます。
4. **ホバー表示**: マクロ変数やMコードにマウスカーソルを合わせると詳細情報が表示されます。

## 設定（Settings）

`settings.json` または VS Code の設定画面から各コードのカラー表示や初期色のカスタム設定が可能です。

```json
{
  "ncCodeHelper.enableOColor": true,
  "ncCodeHelper.colorO": "#FF1744",
  "ncCodeHelper.enableNColor": true,
  "ncCodeHelper.colorN": "#df8337",
  "ncCodeHelper.enableGColor": true,
  "ncCodeHelper.colorG": "#ffa8db",
  "ncCodeHelper.enableMColor": true,
  "ncCodeHelper.colorM": "#eaadfc",
  "ncCodeHelper.enableFSColor": true,
  "ncCodeHelper.colorFS": "#9cc4f8",
  "ncCodeHelper.enableXYZColor": true,
  "ncCodeHelper.colorXYZ": "#76ee86",
  "ncCodeHelper.enableABCColor": true,
  "ncCodeHelper.colorABC": "#b2ff94",
  "ncCodeHelper.enableToolColor": true,
  "ncCodeHelper.colorTool": "#3112e0",
  "ncCodeHelper.enableOthersColor": true,
  "ncCodeHelper.colorOthers": "#f1a88d",
  "ncCodeHelper.enableMacroColor": true,
  "ncCodeHelper.colorMacro": "#e040fb"
}
```

## 実装予定機能
#### タイムスタディの自動計算および出力 
- 早送り速度をF1000などに設定して、XYZの移動距離を算出し、加工時の移動時間を算出
#### 座標数値の誤値検出
- XYZおよびABC軸で小数点抜けがあるかどうかの確認
- 小数点の自動入力
- 極端な座標数値を入力した際の注意出力
- Z0よりマイナス時に移動距離が一定以上になった際の注意出力
